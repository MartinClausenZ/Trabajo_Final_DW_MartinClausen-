Relaciones entre entidades

categories → products (1:N) — Una categoría tiene muchos productos. FK: products.category_id → categories.id. ON DELETE RESTRICT.
products → product_colors (1:N) — Un producto tiene muchos colores/variantes. FK: product_colors.product_id → products.id. ON DELETE CASCADE.
users → carts (1:N) — Un usuario tiene muchos carritos. FK: carts.user_id → users.id. ON DELETE CASCADE. opcional
carts → cart_items (1:N) — Un carrito tiene muchos items. FK: cart_items.cart_id → carts.id. ON DELETE CASCADE. opcional
products → cart_items (1:N) — Un producto puede estar en muchos items de carrito. FK: cart_items.product_id → products.id. ON DELETE RESTRICT. opcional
